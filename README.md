
# Vistaraz

Vistaraz is a fresh, static product front-end for a youth wellbeing support platform. Open `index.html` in a browser to preview it; no build step is required.

## Product scope

### MVP
- Marketing and trust-building homepage
- Optional anonymous/private onboarding choice
- Non-diagnostic, interactive wellbeing check-in
- Support routing: trained listeners, live support, qualified professionals
- Free self-help tools and moderated-community framing
- Membership concept and crisis/safeguarding notice

### Production integrations (next)
- Secure authentication and profile/consent store
- Age gate, guardian consent and safeguarding workflows for under-18 users
- Verified-listener and qualified-professional credentialing
- Encrypted chat, booking, video provider and session feedback
- Payments/subscriptions and institutional partnership portal
- Moderation queue, crisis keyword escalation and region-specific help resources
- Wearable data consent and signal display (never diagnosis)

## Implementation notes

The site deliberately distinguishes support listeners from qualified professionals and says explicitly that the wellbeing check-in is not a diagnosis. The design uses no tracking scripts, third-party component libraries, or runtime dependencies.
