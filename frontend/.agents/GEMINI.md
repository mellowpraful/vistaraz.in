# Vistaraz Project Rules

## Logo
- Always use the Vistaraz logo SVG located at `assets/logo.svg`.
- Reference it in the **header** brand as:
  ```html
  <a class="brand" href="index.html"><img src="assets/logo.svg" alt="Vistaraz" height="48"></a>
  ```
- In pages inside subdirectories, adjust the `src` path accordingly (e.g., `../assets/logo.svg`).
- **Never** use the old text + `<i></i>` brand pattern again.
- The logo features a medical cross with a leaf/stethoscope element in a cyan-to-purple gradient with the tagline "Innovate · Heal · Impact".
- The logo file is at: `assets/logo.png` (PNG format, exact original logo).
